# T17 Teacher Guide: IEBC Certified Integrated Efficiency Consultant

| | |
|---|---|
| **Format** | 8 weeks: weekly 2-hour live session + weekly 60-min lab + capstone |
| **Group size** | Up to 12 |
| **Level** | Advanced (consultants, freelancers, bookkeepers, operators) |
| **Prerequisite** | T02 or T11 completed, or an equivalent skills check |
| **Deliverable** | A complete capstone client project, a panel presentation, a passed exam and the certification |

## Who teaches this

Only teachers who have personally delivered IEBC client builds end to end. The capstone panel
is three people: the lead teacher plus two IEBC consultants who did not teach the cohort.

## Certification standard

A candidate is certified only if all four are met:
1. Every weekly assignment at *Meets* or better.
2. Capstone project scored *Meets* or better on every rubric row by the panel.
3. Written exam: 80% or higher (scenario-based, open-notes, 60 minutes).
4. Professional conduct throughout (data handling, honesty with clients).

Certification is valid for 2 years; renewal requires one continuing-education session per
quarter (any Academy membership session counts) and a short re-check of safety rules.
★ Certification lets graduates **apply** to the IEBC consultant network. It doesn't guarantee
work; say this clearly in week 1.

---

## Weeks 1–2: The IEBC method

**Week 1: Discovery calls and workflow mapping**
- ★ Discovery call structure (30 min): current state, pain points, goals, budget range, decision maker. Role-play in pairs with scripted demo clients; teacher plays one client live.
- ★ Workflow mapping (T12 week 1 method).
- Assignment: a recorded mock discovery call + workflow map.

**Week 2: Scopes clients approve**
- ★ Scope document: outcomes, modules, out-of-scope, timeline, price, acceptance criteria.
- ★ Pricing basics: price on value and effort, never on guesses; IEBC's published price
  structure as a reference.
- Assignment: a scope for the week 1 mock client.

## Weeks 3–4: Building

**Week 3:** websites, hubs and automations (condensed T05 + T12 build weeks); the IEBC build
library approach: reuse proven parts instead of building from scratch.
**Week 4:** AI assistants and agents in client work (T13 safety frame in full); data handling
agreements with clients.
- Assignments: build one module for the mock client; write an agent job description with the six safety requirements.

## Week 5: Finance and operations

Bookkeeping automation (T03, condensed); reporting clients read (one page, five numbers);
★ knowing when to refer to a CPA or attorney.

## Week 6: Delivering and supporting

★ The 6-week delivery framework (Discovery → Architecture → Build → Testing → Launch) with
written approval before each phase; training clients using the Build-Along arc; monthly
support routine; handling scope changes and difficult clients (role-play).

## Weeks 7–8: Capstone

Candidates complete a project for a real client (with the client's written consent) or the
standard sample client provided by IEBC. Week 7 lab = build time with check-ins. Week 8 =
panel presentations (20 minutes + 10 minutes questions) and the written exam.

### Capstone rubric (panel scores each row)

| | Not yet | Meets | Strong |
|---|---|---|---|
| Discovery | Missing goals or decision maker | Clear current state, pains, goals | Quantified before-state |
| Scope | Vague or no out-of-scope | Complete scope with acceptance criteria | Phased with pricing rationale |
| Build | Doesn't work or untested | Working, tested, documented | Reuses library parts; maintainable by client |
| Safety and data | Any of the six agent requirements missing, or real data mishandled | All requirements met | Data handling agreement included |
| Client training | None | Training delivered with the Build-Along arc | Client teaches it back |
| Presentation | Unclear | Clear story: problem → build → result | Honest about limits and next steps |

## Calibration

Panelists score the capstone separately, then discuss. Final score per row is the agreed
score; disagreements of two levels go to the Academy lead.
