# T11 Teacher Guide: AI Automation for Small Business Owners (4-Week Live Cohort)

| | |
|---|---|
| **Format** | 4 weekly live sessions, 90 minutes each, on Zoom, recorded |
| **Group size** | Up to 20 (Producer required above 12) |
| **Level** | Beginner |
| **Demo business** | Lakeside Home Services |
| **Student deliverable** | Four working automations + a 90-day automation plan |
| **Between sessions** | One assignment per week (about 1–2 hours) + optional 30-min office hours |

This is IEBC's flagship live class. It uses the same skills as T02, but taught live with
accountability. Teachers should have taught or completed T02 first.

## Cohort-level objectives

By demo day, every student has four automations running in their business (lead follow-up,
scheduling/reminders, invoice reminders, content or reporting), knows how to maintain them,
and has a written plan for the next 90 days.

## Before week 1

- [ ] Send the pre-class email (Playbook §13.3). Ask students to bring: their top 3 annoying
      tasks, logins to their email/calendar, and free accounts on the assistant and automation tool you'll use.
- [ ] Read every student's enrollment goal (hub → Academy page). Group breakout rooms by
      business type where possible.
- [ ] Set up the class space (shared folder or community) with the worksheets.

---

## Week 1: Time audit and AI basics

**Session objective:** Every student has a scored time audit and a working prompt library of 3 prompts.

| Time | Segment | Details |
|---|---|---|
| 0:00–0:10 | Welcome | ★ Introductions in chat (name, business, most annoying task). ★ Recording notice, data rule, how the 4 weeks work, demo-day goal. |
| 0:10–0:25 | SHOW: the time audit | ★ Score method (frequency × time × frustration). Score Lakeside's tasks live. ★ Good first targets: repetitive, rule-based, low-risk. |
| 0:25–0:40 | BUILD: own time audit | Students fill in the worksheet. Teacher and Producer check in with anyone who hasn't typed anything in 5 minutes. |
| 0:40–0:45 | Break | |
| 0:45–1:00 | SHOW + TRY: prompting workshop | ★ 4-part prompt. Weak vs. strong prompt side by side. ★ Mistake moment (AI invents a policy). Students run the demo prompt. |
| 1:00–1:15 | BUILD: 3 prompts for their top tasks | Breakout rooms of 4–5. Each person shares one prompt; the room suggests one improvement. |
| 1:15–1:25 | SHARE | 3 students share before/after prompts. |
| 1:25–1:30 | Close | Assignment, office-hours time, survey. |

**Assignment (week 1):** Finish the time audit (with "before" hours for the top 3) and save
5 prompts in a prompt library. Use one prompt on a real task and note the time saved.

**Watch for:** Students who say they "have nothing to automate." Ask them to walk you through
yesterday hour by hour; the targets show up.

**Stretch:** Add "ask me 3 questions first" to every prompt.

## Week 2: Leads and follow-up

**Session objective:** Every student builds and tests a lead capture → follow-up automation.

| Time | Segment | Details |
|---|---|---|
| 0:00–0:10 | Welcome + wins | 2 students share a prompt that saved time this week. |
| 0:10–0:25 | SHOW | ★ Trigger → action → check. Build Lakeside: form → spreadsheet → instant acknowledgment → task with AI-drafted reply → 2-day follow-up → ★ stop rule when they reply. |
| 0:25–0:40 | TRY | Students build the same flow with demo data, step by step. Wait for thumbs-up after each step. |
| 0:40–0:45 | Break | |
| 0:45–1:15 | BUILD | Students connect it to their real form/inbox. ★ 3 test runs with fake data before turning on. Producer runs a "stuck" breakout room. |
| 1:15–1:25 | SHARE | 2–3 students screen-share their run history. |
| 1:25–1:30 | Close | Assignment, survey. |

**Assignment (week 2):** Lead follow-up live in their business; screenshot of the flow +
3 successful test runs.

**Watch for:** No stop rule; AI replies sent without review; connecting personal email
accounts instead of business ones.

**Stretch:** Different reply for after-hours inquiries; SMS acknowledgment.

---

## Week 3: Scheduling, invoices and payments

**Session objective:** Every student has appointment reminders and invoice reminders running.

| Time | Segment | Details |
|---|---|---|
| 0:00–0:10 | Welcome + wins | 2 students: first real lead handled by the automation. |
| 0:10–0:25 | SHOW | ★ Booking link with buffers; 24-hour reminder with reschedule link; no-show message. ★ Invoice reminders at 3/10/21 days; ★ AI never changes amounts or due dates. |
| 0:25–0:40 | TRY | Demo booking page + demo invoice reminder. |
| 0:40–0:45 | Break | |
| 0:45–1:15 | BUILD | Students set up whichever of the two matters more first, then the other. Use built-in features of their booking/invoicing tools before custom automations. |
| 1:15–1:25 | SHARE | |
| 1:25–1:30 | Close | Assignment; ★ remind them demo day is next week, and explain the format. |

**Assignment (week 3):** Both automations live; prepare a 3-minute demo-day share.

---

## Week 4: Content, reporting and demo day

**Session objective:** Students add a fourth automation, show their work and leave with a 90-day plan.

| Time | Segment | Details |
|---|---|---|
| 0:00–0:05 | Welcome | |
| 0:05–0:20 | SHOW | ◆ A month of social posts in one session (T06 method, condensed). ★ A weekly numbers report: leads, bookings, invoices overdue, sent automatically every Monday. |
| 0:20–0:40 | BUILD | Students pick content OR weekly report as automation #4. |
| 0:40–0:45 | Break | |
| 0:45–1:15 | DEMO DAY | Each student: 2–3 minutes. *What I automated, before vs. after, what's next.* Class reacts in chat. (Over 10 students: two breakout rooms with teacher and Producer each running one.) |
| 1:15–1:25 | 90-day plan | ★ Weekly 10-minute check routine; ★ next 3 targets from the time audit; ★ when to add a human review step. |
| 1:25–1:30 | Close | Certificate, survey, ★ one mention of course credit and a free call for anyone who wants IEBC to build more. |

**Final assignment:** 90-day plan + before/after hours for all automations.

## Rubric (whole cohort)

| | Not yet | Meets | Strong |
|---|---|---|---|
| Automations | Fewer than 3 working | 4 working, each tested | 4+ working with run history and a weekly check |
| Measurement | No numbers | Before/after hours for each | Also a monthly tracking sheet |
| Plan | None | Next 3 targets listed | Dated plan with review step |

## Office hours (optional, 30 min weekly)

First come, first served screen-share fixes. Producer keeps a queue. Note recurring problems
for the next session's opening and for Guide Change Requests.

## If a student falls behind

Message them after the session. Offer office hours and the recording. A student who is one
automation behind at week 3 can still finish; at demo day they show what they have plus their plan.
